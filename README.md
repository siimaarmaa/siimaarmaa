## About

I work with **Linux administration**, **infrastructure as code**, and **self-hosted services**. The goal is simple: systems that are easy to rebuild, easy to explain, and boring in the best way — predictable, documented, and secure.

If you are here because you care about servers, automation, or running your own lab, you are in the right place.

## Homelab

My homelab is where ideas get a real network, real failures, and real fixes.

- **Linux first** — Ubuntu and Debian servers, systemd, SSH, backups, and least-privilege access
- **Automation** — Ansible playbooks so a host can be rebuilt from code, not from memory
- **Infrastructure as code** — Terraform for repeatable cloud and lab environments
- **Self-hosted services** — reverse proxies, TLS, internal apps, and Raspberry Pi projects
- **Containers and Kubernetes** — compose stacks and cluster tooling when the workload needs them
- **Cloud practice** — Hetzner and similar providers, treated like extra lab racks

I use the lab to test the same patterns I want in production: idempotent configuration, clear inventory, versioned docs, and no mystery snowflake servers.
